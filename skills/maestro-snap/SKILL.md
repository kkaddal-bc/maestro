# maestro-snap

Use this skill when you need to inspect a UI snapshot, compare it against known patterns, and produce a structured report.

## Workflow

1. Read `SCAN-PATTERNS.md` to decide what to look for.
2. Read `OUTPUT-TEMPLATES.md` to format the result.
3. Record only concrete observations.
4. Separate confirmed issues from likely issues.

## Operating rules

- Prefer objective visual facts over interpretation.
- Keep output concise and structured.
- Call out missing context when a snapshot cannot be judged safely.
