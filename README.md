# Maestro

Maestro is a CLI tool for installing and managing AI agent skills.

## Install

```bash
brew tap kkaddal-bc/maestro
brew install kkaddal-bc/maestro/maestro
```

## Usage

```bash
# See all commands
maestro --help

# Install skills into your agent targets
maestro install skills

# List installed skills and their status
maestro list skills

# Update installed skills to latest
maestro update skills
```

## Upgrade

```bash
brew upgrade maestro
```
